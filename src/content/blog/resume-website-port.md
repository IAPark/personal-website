I'm not sure there's anything exciting about a resume or blog website, but
I find that I have a hard time getting my projects to a finished state and a
website seemed like a good way to help with that.

I've had a personal website since I was in college. The first version seems to
have been written back in 2015 in [Polymer](https://polymer-library.polymer-project.org/)
a framework I now don't even remember knowing how to write.

After that for years it used Express and server side React rendering. I think the
last version of that may still be running on a digital ocean account that I can't
seem to get access to. Most recently in 2024 I switched to just using GitHub
pages to host with an action to compile the React into static HTML.

Over the last few months I've become obsessed with some ML related projects I
eventually want to write up and publish as blog posts. After som searching I
decided Astra seemed to be the best modern choice. What's changed in the past
year or so is that AI is now very capable. It was able to reasonably sensibly
port my old website over complete with markdown to define the contents

What's changed since I last tackled a resume website is AI. I feel conflicted
every time I use it, but it's an incredible tool. Porting my existing resume site
to Astra was a breeze. The hard rule I'll stick to though is any text in the
blog, resume, or main pages will be human written.
